HUSH references - bulk import into Zotero
========================================

HOW TO USE
  Zotero toolbar -> the magic-wand icon ("Add Item by Identifier") -> click the
  small arrow to expand it into a multi-line box -> paste BLOCK A below -> Enter.
  Zotero fetches full, correct metadata for each line from CrossRef / PubMed /
  arXiv. Do this instead of importing a hand-written BibTeX file, which would
  carry whatever field errors the repo's own citations have.

  BLOCK B has no machine identifier in the repo. Open each URL and use the Zotero
  browser connector, or search the title in Zotero's "Add by Identifier" after
  looking up its DOI.

  Annotated, grouped versions of all of these - including what HUSH uses each one
  for - are in references.md next to this file.
